# DemoBoss

Live: **https://demoboss.onrender.com/**

Business website for **DemoBoss**, demolition services in Winnipeg: interior strip-outs, garage and shed teardowns, concrete removal, and full site cleanup. Quote requests via the site form, 204-972-0325, or demobosswpg@hotmail.com.

## Stack

Plain static HTML/CSS/JS in `index.html`. No build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Deployed via GitHub Pages on pushes to `main`.
